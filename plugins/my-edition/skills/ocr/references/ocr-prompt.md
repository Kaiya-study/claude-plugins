# 文字起こしプロンプト

そのまま使う。書名・章・ページ範囲だけ差し替える。

---

以下の画像は『{書名}』第{章}章、印刷 p.{開始}–p.{終了} のスキャンです。
ページの内容を Markdown + LaTeX で**忠実に**文字起こししてください。

## 要件

- 数式は LaTeX で書く。**偏微分記号・添字の上下・プライム記号(')・太字ベクトルを正確に再現**すること
- 番号つきの式には `\tag{}` で式番号を付ける。番号は原文のまま。振り直さない
- 日本語の本文もそのまま書き起こす。要約・言い換えをしない
- 各ページの冒頭に出典コメントを入れる： `<!-- source: {ファイル名} / printed page {印刷ページ} -->`
- 図・表は `[図 3.2: キャプション]` の形で位置だけ記録する

## 式番号の対応付け（いちばん間違えやすい）

式番号はページの右端に離して置かれ、式本体と**縦位置がずれて見える**ことがあります。
分数・場合分け・行列など背の高い式では、番号が1つ下の式の高さに来ることがよくあります。

- **番号は必ず「式」に付きます。**「である．」のような地の文には付きません
- 上から順に、**式の個数と番号の個数を数えて**対応させてください
- 番号のない式（本文中に挟まれた途中式）もあります。**無理に全部へ番号を振らないでください**
- 対応に自信がない箇所は `[番号の対応要確認]` と書いてください

## 忠実性について（重要）

**原文を直さないでください。** 物理的・数学的におかしく見える箇所があっても、
書いてあるとおりに写してください。

たとえば `(∂μ_i/∂N_i)_{S,V,N_i}` のように、微分する変数を固定変数にも並べている表記があります。
意味としては「他の N を固定」でしょうが、**原文がそう書いているならそのまま**にしてください。
プライムを補ったり、添字を直したりしないでください。

読み取れない箇所は `[判読不能]` と書いてください。文脈からの推測で埋めないでください。

原文の粗さは、後の工程で「原文はこう書いているが、意味はこうである」と**明示して**扱います。
ここで黙って直されると、その情報が永久に失われます。

## 出力

文字起こし結果だけを出力してください。解説・要約・感想は不要です。

## 補足（この工程を実行する側への注意）

- 1回の投入は12ページ前後まで。それ以上入れると精度が落ち、上限にも早く当たる
- 画像は解像度を落とさない。数式の添字は小さく、圧縮すると真っ先に潰れる
- 同じ本の続きを処理するときは、`ledger.md` の記号表を先に読ませておくとよい。
  「この本では太字が3次元ベクトル、上付き矢印が4元ベクトル」と分かっている状態で読むほうが、
  白紙で読むより正確に転写できる
