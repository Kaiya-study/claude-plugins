
書くのは**断片2種類**で、テンプレートの差し込み口に入る。連結は `assemble.sh` / `.ps1` がやる
（`build/SKILL.md` 手順6）。テンプレートの CSS と JavaScript がここのクラス名を前提にしているので、
**名前を変えない。**

| 書くもの | 入る場所 | 中身 |
|---|---|---|
| `parts/rail.html` | `<!-- RAIL -->` | サイドバー（下記「目次とプロファイル」） |
| `parts/chNN.html` | `<!-- CONTENT -->` | 本文と補完。**章ごとに1つ** |
| `parts/colophon.html` | `<!-- CONTENT -->` の最後 | 巻末。**章の断片には書かない**（下記「巻末」） |
| `.my-edition/b64/*.txt` | `{{FILE:}}` で参照 | 図の base64。**断片に直接書かない**（下記「図」） |

**断片に `<html>` `<head>` `<body>` `<main>` を書かない。**テンプレートが持っている。
`parts/title.txt` には書名を1行だけ書く（記号 `'` `<` `>` `&` は使わない）。

## 全体

```html
<p class="chap-line">第3章　熱力学関数と平衡条件</p>
<p class="editors-note">この版は、原著の本文に、読み手が自分で検証できる粒度の途中式を補ったものです。補った部分は色のついた欄に分けてあり、原著の記述と混ざりません。</p>

<h2 id="s34"><span class="secno">3.4</span>熱力学不等式</h2>
<p>本文…</p>
```

- `h2` の `id` は目次のリンク先になる。`s34` のように節番号から作る
- 本文の段落は素の `<p>`。装飾しない
- **本文データを持ち込んで作った版では、`editors-note` にその旨を足す。**
  「本文は読者が用意したデータ（{srcNote}）を使っています。この道具は文字起こしをしていません。」
  忠実さの保証が変わるので、読む側に見えている必要がある（`shared/state-format.md`）

## 数式

```html
<div class="eq" data-num="(3.33)"
     data-tex="\begin{vmatrix} \cdots \end{vmatrix} \ge 0"
     data-ctx="2次形式が正値であるための小行列式の条件を述べた箇所。">
  <div class="eq-line">
    <div class="eq-body">\[ \begin{vmatrix} \cdots \end{vmatrix} \ge 0 \]</div>
    <span class="eq-num">(3.33)</span>
  </div>
  <div class="eq-foot"></div>
</div>
```

- `data-tex` — LaTeX ソース。「TeXをコピー」と質問文の組み立てに使う
- `data-ctx` — 前後の文脈を一文で。質問文に同梱される
- `.eq-foot` は空のまま置く。ボタンと逆引きは JavaScript が入れる
- **式番号は原文のまま。**振り直さない

## 補完（行間）

補完がある式だけ、`.eq` の中に続けて置く。

```html
  <div class="gap"><div class="gap-inner"><div class="gap-card">
    <span class="gap-tag">補完</span>
    <p>本文…</p>
    <div class="sub">\[ 途中式 \]</div>
    <p>…</p>
  </div></div></div>
</div>
```

- **`class="gap"` だけを書く。`is-open` を付けない。**補完は既定で閉じておく。
  開閉はテンプレートの「途中式をひらく」ボタンが受け持つ。
  出力に `class="gap is-open"` と書くと、そこだけ開いた状態で始まってしまう
- `.gap-tag` は必ず「補完」。**番号を振らない**（「行間 01」は注釈集の書き方）
- `.sub` は補完の中の別行立て数式。横に長い式でもページ全体が横スクロールしないための器
- 「この説明について聞く」の質問チップは JavaScript が入れる。書かない

## 注釈（原著の脚注）

**注釈は原著の記述である。**補完と同じ見た目にしない。地色を付けず、細い罫で示す。
読者が「本に書いてあったのか、こちらが補ったのか」を見分けられなくなるのが、いちばん避けたい失敗。

**本と同じく、その段落のすぐ下に置く。節の末尾にまとめない。**

```html
<p>気体分子運動論<a class="noteref" data-note="n1-1">†</a>によれば，……</p>
<p class="note" id="n1-1"><span class="note-mark">†</span>例えば, Chapman と Cowling (1970), 5 章を参照.</p>
```

- **マーカーは原文どおり。**`†` `††` `*` など、本が使っている記号をそのまま使う。**振り直さない**
- **`id` は文書内で一意にする。**`n<章>-<通し番号>` の形（`n1-1` `n2-3`）。
  本1冊が1ファイルなので、章をまたいで重複してはいけない
- `data-note` は `id` と**完全に一致**させる
- **`.note` は、その注釈が付いた段落の直後に置く。**節末にまとめると、
  同じ節に `†` が複数あるとき**どれがどれか分からなくなる**（実際にそうなっていた）
- **「原著のみ表示」でも消さない。**原著の記述だから。補完とは逆の扱いになる
- 注釈の中に式が出てきたら、本文と同じく `\( \)` の中に入れる
- **注釈を1つにまとめない。**同じ `†` でも、**原著のページが違えば別の注釈である。**
  つないで1本にすると、原文にない文がひとつできる。
  実際に「井上 (1952) を参照．／ 今井(1979)を参照．」のように、
  **別々の注釈2本が `／` でつながれて、8本あった注釈が6本に減っていた**
- **数を必ず確かめる。**文字起こし（`text/`）にある注釈の数と、出力の `.note` の数を突き合わせる。
  合わなければ、どこかで落としたか、まとめている

クリックでその注釈へジャンプ、ホバーでポップアップ——**テンプレートが自動でやる。書かなくてよい。**

## 図

**原著の図は、元のスキャンから切り出して埋め込む。**

**base64 を断片に直接書かない。**別ファイルに置き、`{{FILE:}}` で参照する。
連結のときに差し込まれる。図の実体は数十KBから百KB あり、断片に書くと
**そのぶんを毎回書き直すことになる**（章ひとつが70KBのところ、図で900KBまで膨らんだ実例がある）。

```html
<figure class="fig">
  <img src="data:image/png;base64,{{FILE:.my-edition/b64/p026_fig1.txt}}" alt="図 2・1 流線">
  <figcaption>図 2・1　流線</figcaption>
</figure>
```

- 切り出した画像は `.my-edition/b64/<ページ>_<図番号>.txt` に、**base64 だけを1行で**置く
  （`data:image/png;base64,` の前置きは断片の側に書く）
- パスは**作業フォルダからの相対**で書く。連結コマンドを走らせる場所が基準
- **描き直さない。**SVG などで作図し直すと、原著の図と補ったものの区別が消える。
  本文の記法を黙って直さないのと同じ理由
- キャプションは原文どおり。番号も原文のまま
- 図の読み方に説明が要るときは、**補完の側に書く**。本文と図には手を入れない
- 切り出しは元画像の該当領域をそのまま。傾き補正や色調整はしてよいが、内容は変えない

## 式に番号がない本

原著が式に番号を振っていない本もある。その場合、相互参照・逆引きが使えなくなるので、
**この版で通し番号を振る**。

- **原著の番号形式と見分けがつく形にする。**例：`〔9-1〕`（ページ由来の亀甲括弧）。
  原著が `(2.41)` 形式を使う本と混ざらないようにする
- `editors-note` に「式番号はこの版で付けたものです。原著に番号はありません」と明記する
- 振った番号は台帳にも記録し、以後の章でも同じ規則を使う

## 相互参照

本文・補完の中で式番号に言及するときは、必ずリンクにする。

```html
<a class="eqref" data-ref="(2.8)">(2.8)</a> で <span class="mj">\(a=1\)</span> とした場合にほかならない
```

- `data-ref` は `data-num` と**完全に一致**させる。括弧やスペースまで揃える
- クリックでジャンプ、ホバーでポップアップ、逆引き（「この式を使う式」）はこれを元に自動生成される
- **原文に既にある式番号の言及を、リンクにする。**リンクを張るために参照を新しく書き足さない
  （それは原文を書き換えることになる）

## 本文中のインライン数式

```html
<span class="mj">\(e^{-x^{2}}\)</span>
```

`class="mj"` は目印。MathJax は `\( \)` を見て処理するので必須ではないが、付けておく。

## 山括弧（いちばん多い表示崩れ）

**`<` と `>` を、数式の外に生のまま置かない。**ブラウザがタグの開始と読み、
そこから先の表示がまとめて壊れる。中身は無事なのに画面が壊れるので、原因が分かりにくい。

期待値・ブラケット記法・不等号で出やすい。

| 書きたいもの | 誤り | 正しい |
|---|---|---|
| 期待値 | `<x>` | `\(\langle x \rangle\)` |
| ブラケット | `<ψ|φ>` | `\(\langle \psi \vert \varphi \rangle\)` |
| 地の文の不等号 | `a < b` | `\(a < b\)`、または `a &lt; b` |

- **数式は必ず `\( \)` か `\[ \]` の中に入れる。**中に入っていれば MathJax が処理する
- 数式にしない `<` `>` は `&lt;` `&gt;` にする
- **`data-tex` と `data-ctx` の属性値も同じ。**属性の中でも `<` はタグとして読まれる
- 出力後、`<` が数式の外に生で残っていないか一度検索して確かめる

## MathJax に入っていないコマンド（ページ全体が白紙になる）

`tex-svg.js` には TeX の全機能が入っているわけではない。**入っていないコマンドに出会うと、
MathJax は追加部品をネットから取りに行く。**生成物はオフラインで開く前提なので取得は失敗し、
**そこで組版全体が中断する。**その式だけが崩れるのではなく、**ページ上の数式が1つも表示されない。**

実際に起きた例：本文で `\boldsymbol` を使った章が、数式ゼロで出力された。原因が分かりにくいのは、
HTMLもMathJax本体も設定も正常で、どこも壊れているように見えないため。

| 書きたいもの | 使わない | 使う |
|---|---|---|
| 太字のベクトル | `\boldsymbol{u}` | `\mathbf{u}` |
| ブラケット・期待値 | `\bra` `\ket` `\braket` | `\langle` `\rangle` |
| 取り消し線 | `\cancel{x}` | 補完の文章で説明する |
| 色 | `\color` `\textcolor` | 使わない（補完は地色で区別している） |
| 化学式 | `\ce{...}` | 通常の記法で書く |
| 単位記号 | `\upmu` `\degree` `\celsius` | `\mu` `^\circ` |
| 物理演算子 | `\dv` `\pdv` `\qty` | `\frac{d}{dx}` `\partial` `\left( \right)` |
| 場合分け・行列の別記法 | `\dcases` `\smallmatrix` | `\begin{cases}` `\begin{pmatrix}` |

- **原著が太字ベクトルを使っていても `\mathbf` に置き換える。**字体はわずかに変わるが、
  数式が1つも出ないよりよい
- 迷ったら **`amsmath` の範囲までで書く。**そこまでは本体に入っている
  （`\operatorname` `\gtrsim` `\varPhi` `\begin{align}` などは使える）
- テンプレート側でも自動取得を止めてあるので、万一使っても**そのコマンドが赤く出るだけで、
  ほかの数式は表示される**。これは保険であって、避けるのが先

## 巻末

**`parts/colophon.html` に単独で置く。章の断片に書かない。**
章ごとに書くと、章を足したときに**前の章の巻末が本の途中に残る。**
「第1章を生成済み。第2章以降は未作成です」が真ん中に出てしまう。

```html
<div class="colophon">
  <p>第2章（2-1 〜 2-6、印刷 p.14–35）まで生成済み。第3章以降は未作成です。</p>
  <p>原本：{書名}／{著者}／{出版社}。この版は原本から自分用に作成したものであり、配布しないでください。</p>
</div>
```

- **章を足すたびに、このファイルを上書きする。**書くのは常に**いまの到達点**だけ
- 連結のときは**いちばん最後に渡す**（`build/SKILL.md` 手順6）
- 書誌と「配布しない」旨は必ず入れる
- 本文データを持ち込んだ版では、その出どころと、忠実さを保証できない旨もここに書く
