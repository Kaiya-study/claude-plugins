# オフセット較正の手順

目次から分かるのは**印刷ページ番号**。手元にあるのは**ファイル番号**。
この2つは、表紙・扉・まえがき・ローマ数字ページの分だけずれる。
「目次を読む」だけでは章の範囲は決まらない。

## 手順

### 1. 目次を読む

最初の10〜12ファイルだけを低解像度で読み、目次を特定する。
章題・開始印刷ページ、取れるなら節の位置も取る。

### 2. ノンブルだけを送ってズレを測る

**ページ全体を送ってはいけない。** ノンブル（ページ番号）のある余白だけを切り出して送る。
切り出しはローカル処理なので無料で、送る画像も数百バイトで済む。

上下どちらに振ってあるかは本による。最初の1枚で位置を確認してから、以降は同じ領域を切る。

離れた2点で測る。

```
ファイル 050 → 印刷 039  →  オフセット +11
ファイル 350 → 印刷 339  →  オフセット +11   ✓ 一致
```

一致すれば、その本は全体を通してオフセットが一定と判断してよい。

### 3. 一致しない場合

途中に折込や中扉がある。**その区間だけ二分探索で詰める**。
一致した2点の間で中点を測り、どちら側でずれているかを見る。数回のプローブで境界が出る。
区間ごとに異なるオフセットを `calibration.probes` に記録する。

### 4. 章の範囲を確定し、1点だけ答え合わせ

```
第3章 印刷 87–124  →  ファイル 98–135
```

確定したら、**先頭ファイルの上部だけを読み、本当にその章の扉かを確認する**。
ここを飛ばすと、以降のすべてが1ページずれたまま進む。

### 5. 範囲を前後1ページ広げる

章の境界で式や証明がまたぐことがある。±1ページ広げても数円で、事故が防げる。
`state.json` の `chapters[].files` には広げたあとの値を入れる。

## 較正が要らない場合

**章ごとにフォルダが分かれているなら、この手順はすべて不要。** `calibration.mode` を
`perChapterFolder` にして、フォルダ名から章を対応づける。

**分けるよう勧めなくてよい。**較正は上の手順で自動的に済むので、一気に取り込んだ本でも
そのまま進められる。分けるかどうかは、紙束を仕分ける手間を先に払うかどうかの好みの問題。
聞かれたときだけ「章ごとに分かれていれば較正が要らない」と答える。

## ノンブルが読めない本

一部の専門書はノンブルが小さい、あるいは飾りに紛れて読み取れない。その場合の代替。

**柱（ランニングヘッド）方式** — 全ページの上部10%だけを切り出して一括で読み、
柱に刷られた章名から「どのファイルがどの章か」を直接判定する。
切り出しはローカル処理なので無料、送るのは細い帯だけなので安い。

ただし柱のない本もある。これは第2手段。両方だめなら、読者に章の先頭ページ番号を
手で教えてもらう（目次を見ながら数ページ確認すれば済む）。

## 副産物

OCR結果には、必ず出典をメタデータとして残す。

```markdown
<!-- source: page_108.jpg / printed page 97 -->
```

これがあれば較正が後から検算できるし、誤りを見つけたとき原本のどこを見ればよいかが即座に分かる。
