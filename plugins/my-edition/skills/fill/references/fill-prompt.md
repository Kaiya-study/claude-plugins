# 行間の探索と充填のプロンプト

**探索と充填を分ける。**同時にやらせると、埋めやすいものだけを拾って網羅性が落ちる。

---

## 【探索】著者が省略しているものを列挙する

以下は『{書名}』{章節}の本文です（文字起こし済み・原文どおり）。

```
{本文}
```

この本文の中で、**著者が省略している推論・計算・前提**をすべて列挙してください。
**埋めないでください。**この段階では、どこに行間があるかを挙げるだけです。

## 探すもの

1. **計算の飛躍** — 「〜より」「整理すると」「明らかに」の一語で複数の操作をまとめている箇所
2. **動機の省略** — なぜその変形をするのか、なぜその置換を思いつくのかが書かれていない箇所。
   ただし**本の議論の筋そのものは対象外**（下記）。計算上の工夫の動機までにとどめます
3. **前提の暗黙化** — 収束性、可換性、正則性など、使っているのに述べられていない条件
4. **既出への無言の参照** — 番号を挙げずに前の結果を使っている箇所
5. **記号の粗さ** — 表記が厳密でない箇所（例：微分する変数を固定変数にも並べている）。
   これも行間の一種です
6. **符号・分岐の消失** — 二乗して解く、平方根を取るなどで情報が落ちている箇所

## 埋めてはいけないもの

**本の主張そのものは、行間ではありません。**

| | 例 | 扱い |
|---|---|---|
| **作業** | 計算、代入、変形、既知の定理の適用 | 埋める |
| **主張** | なぜその方針を取るのか、何を仮定しているのか、この結果が何を意味するのか | **埋めない** |

たとえば「この対称性を課すと保存量が出てくる」という筋で議論が組み立てられているとき、
**その筋自体は本の中身です。**先回りして説明すると、読者は要約を読んで分かった気になり、
本を読まなくなります。それでは、その本を買った意味がありません。

**境目が怪しいものは、挙げないでください。**「作業とも主張とも言えるが、たぶん主張寄り」
というものに手を出すと、著者が言っていないことを著者の話であるかのように書くことになります。
迷ったら落としてください。

## 出力

```
- [計算の飛躍] 式(2.11)→(2.12)：「そこで I² を考える」の一行。二乗する動機と、
  1変数積分の積を二重積分と読み替える根拠の二つが省略されている
- [前提の暗黙化] 式(2.12)：逐次積分と重積分の一致に Tonelli の定理を使っているが言及がない
- [記号の粗さ] 式(2.15)：(∂μ_i/∂N_i)_{S,V,N_i} は、微分変数を固定変数にも並べている
```

各項目に、対応する式番号または位置を必ず付けてください。

---

## 【充填】列挙されたものを一つずつ埋める

以下の行間を埋めてください。

**対象：** {探索で挙がった1項目}

**本文（原文どおり）：**
```
{該当箇所と前後}
```

**この本で既出の式・記号：**
```
{ledger.md の関連部分}
```

**読者のレベル：**
```
{profile.md}
```

## 書き方の基準

目的は「正しい答えを与えること」ではなく、**読者が自分で検証できる形にすること**です。
次の4つを必ず満たしてください。

1. **1ステップ1操作。** 「両辺を微分して部分積分した」を一行で済ませない
2. **根拠の明示。** 「(1.7)より」「Tonelli の定理により」など、使った規則を必ず書く
3. **飛躍の自己申告。** 埋めきれない箇所は「ここは天下り的だが」と書く。黙って飛ばさない
4. **検算の手がかり。** 「a=1 とすれば (2.8) に一致する」「次元解析で確かめられる」など、
   読者が自分で確かめる道具を渡す

## 読者のレベルに合わせる

上のプロファイルで **既知** とされている操作は、説明せずに使ってください。
それはこの読者にとって行間ではありません。**怪しい** は途中式を書き、**未習** は定義から書きます。

## 原文を直さない

原文の記法が粗い場合、**本文を直すのではなく、補完の中で明示して**扱ってください。

> 原文は `(∂μ_i/∂N_i)_{S,V,N_i}` と書いているが、N_i で微分しながら N_i を固定するのは
> 意味をなさない。ここは他の N を固定する意味と読むべきである。

黙って直すと、読者は「本にそう書いてある」と信じてしまいます。

## 参照

既出の式を使うときは、必ず式番号を明記してください。上の一覧にない式を使う必要がある場合は、
**推測で書かず**、「(1.7) が手元の一覧にありません」と述べてください。

## 出力

```markdown
### 補完：式(2.12)

参照：(2.11)

{本文}
```

解説の前置き（「以下に説明します」など）は不要です。内容だけ書いてください。
